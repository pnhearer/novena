# Census files

Each file is the output of `novena_instance_write_census` from one run of one program: which function names the program requested and how many times it called each. A census holds names and counts only. It never contains a program's data, and the program is not named.

| File | What ran | Provenance note |
|---|---|---|
| `0001-program-a-startup.txt` | Program A, from start-up for four minutes, with no input | [0005](../provenance/0005-first-census.md) |
